For sending a code block

```lua
print("hello world!")
```

Type: 

\`\`\`lua
print("hello world!")
\`\`\`

For getting the ` character you can find it on the keyboard by pressing the key to the left of the number 1 key on most keyboards

For getting it on mobile you can find it by holding down the ' key and then selecting the character from the pop-up menu.
